# Logo oficial Payway — solo checkout

Ícono del método de pago en el checkout WooCommerce (`WC_Payment_Gateway_Payway::$icon` → filtro `woocommerce_payway_icon`).

| Archivo | Uso |
|---|---|
| `payway-official-48.png` | **Activo** en el gateway (48×48, tile azul + W + “payway”) |
| `payway-official-96.png` | Variante @2x |
| `payway-official-256.png` | Master raster cuadrado |
| `payway-official-square.png` | Recorte del PNG fuente (sin resize extremo) |
| `payway-official.svg` | Logotipo oficial horizontal (fuente payway.com.ar) |
| `payway-official-square.svg` | Misma marca en tile azul cuadrado (derivado del SVG) |

- Raster: `/Downloads/payway-logo.png` (recortado y escalado).
